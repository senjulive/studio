# AstralCore - Quantum AI Trading Platform

![AstralCore Banner](https://img.shields.io/badge/AstralCore-Quantum%20Nexus%20v3.76-blue?style=for-the-badge&logo=bitcoin&logoColor=white)

A revolutionary cryptocurrency trading platform powered by quantum AI technology. Built with Next.js 15, TypeScript, and modern React patterns.

## 🚀 Features

- **Quantum AI Trading Bot** - Advanced algorithmic trading with neural networks
- **Real-time Market Data** - Live cryptocurrency market analysis
- **Secure Wallet Management** - Multi-currency wallet with advanced security
- **KYC Verification** - Complete identity verification system
- **Squad System** - Social trading and referral management
- **Admin Dashboard** - Comprehensive platform management tools
- **Responsive Design** - Optimized for desktop and mobile devices
- **PWA Support** - Progressive Web App capabilities

## 🛠️ Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Radix UI
- **Animation:** Framer Motion
- **Icons:** Lucide React
- **Form Handling:** React Hook Form + Zod
- **Charts:** Recharts
- **PWA:** Next.js PWA support

## 📋 Prerequisites

- Node.js 18+

## 🏃‍♂️ Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/astralcore.git
cd astralcore
```

### 2. Install Dependencies

```bash
npm install
# or
yarn install
```

### 3. Environment Setup

Copy the environment variables template:

```bash
cp .env.example .env.local
```

Update the environment variables in `.env.local` as needed.

### 4. Development Server

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

### 5. Build for Production

```bash
npm run build
npm start
```

## 🌐 Deployment

### Netlify (Recommended)

1. **Connect Repository:**
   - Fork this repository to your GitHub account
   - Connect your GitHub account to Netlify
   - Select the AstralCore repository

2. **Build Settings:**
   - Build command: `npm run build`
   - Publish directory: `.next`
   - Node version: 18+

3. **Environment Variables:**
   - Add your environment variables in Netlify dashboard
   - Set `NODE_ENV=production`
   - Set `NEXT_TELEMETRY_DISABLED=1`

4. **Deploy:**
   - Push to main branch to trigger automatic deployment
   - Netlify will build and deploy automatically

### Manual Deployment

```bash
# Build the application
npm run build

# Export static files (if needed)
npm run export

# Start production server
npm start
```
